# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be respectful, assume good faith, and keep discussion technical and
constructive. Harassment or abuse of any kind is not tolerated.

Report unacceptable behavior privately through the repository maintainers
(GitHub Security Advisories or a direct message to a maintainer). Maintainers
will review and respond to every report.
